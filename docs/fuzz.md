# Differential tensor corpus

Ticket #6. Sixteen rectangular power-of-two shapes, each computed three ways:

- `matmul(A, B)`;
- `matmul_bt(A, transpose(B))`;
- `matmul_tn(transpose(A), B)`.

All three must produce the same FNV-1a hash over the output `F32` bits.

## Result

16/16 cases pass, including `128x128x128`, `128x2x64`, `32x128x128`, and
`64x128x128`. No index/layout divergence.

Raw: [`bench/einsum/fuzz.csv`](../bench/einsum/fuzz.csv), generated by
`tests/fuzz_tensor.bend` (deterministic xorshift seeds).

## Limits

The kernels require power-of-two padded storage (`Array.new` takes a depth).
Non-power-of-two logical shapes need a padded copy and a submatrix compare;
that is not covered here. The corpus tests rectangular power-of-two shapes and
the three index layouts, not arbitrary `M,N,K`.

The three implementations agree with each other; cross-backend agreement is
#2's result (bit-identical C/Node/Bend/GPU).
