# Softmax sums to 1: not in F32

Ticket #7 asked whether `softmax(xs)` sums to exactly 1 for a non-empty list.
It does not, in general, because the arithmetic is `F32` and Base exposes no
axioms for `exp`/`div` associativity.

## Counterexample

Input: `[0.5, 0.25, 0.125, 0.0625]`.

```
softmax → [0.516, 0.258, 0.129, 0.0645]
sum     → 0.99999994
sum == 1.0 → False
```

Other small cases happen to land on 1.0 exactly (see the CSV); that is luck,
not a theorem. A law of the form `{sum(softmax(xs)) == 1.0 : F32}` is false and
`bend PROOF.bend` rejects it.

## What would be provable

A tolerance law needs an ordered real model and axioms for `F32.exp`, `F32.div`
and rounding. Base has no such axioms (`F32` is explicitly axiomatic), so the
correct statement is a *test*, not a law:

- check `abs(sum - 1) <= 2^-20` on the corpus;
- keep the exact-equality claim out of `LAWS.bend`.
